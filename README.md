## Project Overview
This is our Data Science II Final project. We worked with the Heart Disease dataset from Kaggle to determine what factors can predict the likelihood that a patient has heart disease. This project includes creating three classification models (Logistic regression, KNN, and decision trees) to determine which one best fits our client's needs. If you want to explore the dataset yourself, use this link: 
(Heart Disease Dataset)[https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset](url)

## Key details for models
1) Each model used the same preprocessed data, ensuring all models worked with the same cleaned data.
2) Each model used the same train/test split to ensure fairness. The split was common, with about 80% of data points allocated to the training set and 20% allocated to the testing set.
