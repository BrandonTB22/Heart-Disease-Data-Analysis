# Data-Science-Final
This is our repo for our Data Science II Final project. We are working with the Heart Disease dataset from Kaggle to determine what factors can predict weather or no a patient has heart disease. This project includes a creation of three classification models to determine which one is the best predictor for heart disease. If you want to explore the dataset yourself, click this link: 
[https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset](url)
